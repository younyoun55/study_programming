# 課題一覧

各課題が終わったら `[ ]` を `[x]` に変えて進捗を管理しましょう。

## 基本（レッスン1）

- [ ] 課題1-1：自分の仕事や学習内容を3行で説明してもらい、2回修正を依頼する
- [ ] 課題1-2：同じ会話の中で、前の回答を使った追加質問を3回以上行う

## 指示の出し方（レッスン2）

- [ ] 課題2-1：「悪い依頼」と「良い依頼」で同じテーマの回答を比べ、違いを3点書き出す
- [ ] 課題2-2：役割（専門家など）を指定した依頼を行い、結果の変化を記録する
- [ ] 課題2-3：大きなテーマ（例：旅行計画）を、構成→詳細の2段階で依頼する

## Claude Code（レッスン3）

- [ ] 課題3-1：練習フォルダでファイルを新規作成してもらう
- [ ] 課題3-2：既存のファイルの一部を修正してもらい、`git diff` で変更箇所を確認する
- [ ] 課題3-3：コマンドを実行して結果の説明を求める（例：ファイル一覧の表示）

## 設定と再利用（レッスン4）

- [ ] 課題4-1：CLAUDE.md を作成し、ルールを3つ以上書く
- [ ] 課題4-2：CLAUDE.md のルールを1つ変え、回答が変わったことを確認する
- [ ] 課題4-3：よく使う依頼を1つ選び、スラッシュコマンドとして再利用する方法を調べて試す

## 振り返り

- [ ] 学んだことを5行でまとめ、次に試したいことを1つ書く
