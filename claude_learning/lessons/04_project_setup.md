# レッスン4：CLAUDE.md と設定で毎回の前提を共有する

## CLAUDE.md とは

プロジェクトのルートに置く Markdown ファイルです。
Claude Code は作業開始時にこれを読み、プロジェクトの前提として扱います。

書いておくと良い内容の例：

- プロジェクトの目的と構成
- 文章のトーン、用語の統一ルール
- テストや確認の手順
- 触ってはいけないファイル

```markdown
# CLAUDE.md

## 目的
Claude の使い方を学ぶための練習資料を管理する。

## ルール
- 説明文は日本語で書く
- 見出しは「##」から始める
- 変更後は内容を要約して報告する
```

## /init で作成する

Claude Code で `/init` を実行すると、プロジェクトを読み取って CLAUDE.md の下書きを作成できます。
内容は必ず自分で確認し、不要な部分は削りましょう。

## 繰り返しの作業を再利用する

同じ依頼を何度もする場合は、次の仕組みを検討します。

- **スラッシュコマンド**：よく使う指示を名前付きで呼び出す
- **Skills**：特定の作業手順をまとめて再利用する
- **設定（settings）**：許可するコマンドなどを管理する

## やってみよう

- [ ] 練習フォルダに CLAUDE.md を作り、「回答は日本語で、結論を最初に書く」というルールを書く
- [ ] Claude Code に文章の説明を依頼し、ルールが反映されているか確認する
- [ ] ルールを変えて（例：「箇条書き優先」）、結果がどう変わるか比べる
