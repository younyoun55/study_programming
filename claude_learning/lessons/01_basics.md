# レッスン1：Claudeとの基本的なやり取り

## 1. 会話は「往復」で進める

Claudeは一度の回答で完璧を目指すより、**やり取りを重ねて磨く**のが基本です。

- 1回目：ざっくり依頼する
- 2回目以降：「もっと短く」「表にして」「この部分を直して」と修正する

## 2. 同じ会話の中では文脈が残る

同じ会話内では、前に話した内容を覚えた状態で答えます。
「さっきの案をもう少し詳しく」のように指示代名詞を使えます。

ただし、会話を新しく始めると文脈はリセットされます。
前提を引き継ぎたいときは、要点を書いて渡しましょう。

## 3. 回答は必ず確認する

Claudeは誤った内容を自信を持って書くことがあります。
特に次のものは、人間側で確認しましょう。

- 数値、日付、固有名詞
- 法律、医療、金融に関わる内容
- コードを実際に動かす前の動作

## 4. 得意・不得意の目安

| 得意 | 不得意・注意 |
|------|--------------|
| 文章の要約・校正・翻訳 | 最新情報（学習時点以降の出来事） |
| アイデア出し、構成作り | 正確な計算を暗算で行うこと |
| コードの説明・修正案 | 存在しないAPIや関数を書いてしまうこと |

## やってみよう

- [ ] 「Claudeとは何ですか？3行で説明して」と依頼する
- [ ] その回答に対して「小学生にも分かる言葉に直して」と修正を依頼する
- [ ] 「さっきの説明の要点を箇条書きにして」と、文脈を使った依頼をしてみる
