# レッスン2：伝わる指示の出し方

## 基本の型

次の4つを入れると、回答の精度が上がります。

| 要素 | 例 |
|------|----|
| 目的 | 「社内報に載せる文章を作りたい」 |
| 背景・前提 | 「読者は入社1年目の社員です」 |
| 条件・制約 | 「300字以内、敬語で」 |
| 出力形式 | 「箇条書きで、最後に一言まとめを付けて」 |

### 悪い例と良い例

- 悪い例：「メールを書いて」
- 良い例：「取引先に納期の延期をお願いするメールを書いてください。
  理由は部品の遅延です。丁寧だが簡潔に、件名も付けてください。」

## 役割を与える

「あなたは経験豊富な編集者です」のように役割を指定すると、
視点や言葉遣いが安定することがあります。

## 段階的に頼む

大きな依頼は分けると失敗が減ります。

1. まず構成案を出してもらう
2. 構成を確認・修正する
3. 各章を書いてもらう

## 良い回答が出なかったときの直し方

- 何が違うかを具体的に伝える（「例が抽象的すぎる」）
- 良かった部分を残すように伝える（「2段落目の書き方は良いので維持して」）
- 最初からやり直す場合は、条件を整理して新しく依頼する

## やってみよう

- [ ] 同じテーマ（例：週次の業務報告）を、悪い依頼と良い依頼の2通りで試し、回答の違いを比べる
- [ ] 「あなたは〇〇の専門家です」という役割付きで依頼し、結果を比べる
