# レッスン3：Claude Code の基本操作

Claude Code は、ターミナルやIDEからClaudeにプロジェクトを読ませ、
ファイルの編集やコマンド実行まで依頼できるツールです。

## 起動と終了

```bash
cd 作業したいフォルダ
claude
```

作業フォルダを指定して起動すると、そのフォルダ内のファイルを対象に作業します。

## 基本の依頼

- 読み取り：「README.md の内容を要約して」
- 編集：「README.md の見出しを整えて」
- 実行：「テストを実行して、結果を教えて」

## 操作の確認（許可）

Claude Code はファイルを書き換えたりコマンドを実行する前に、許可を求めることがあります。
内容を読んでから承認しましょう。見慣れないコマンドは特に確認が大切です。

## よく使うスラッシュコマンド

| コマンド | 役割 |
|----------|------|
| `/help` | 使えるコマンドの一覧を表示 |
| `/clear` | 会話をリセットする |
| `/compact` | 会話の要約を残して、文脈の量を減らす |

## 変更を取り消す・確認する

- Claude が行った変更は、Git を使っていれば `git diff` で確認できます
- 不要な変更は `git checkout -- ファイル名` などで戻せます（必ず内容を確認してから）
