# Claude 利用学習プロジェクト

Claude（チャット、Claude Code）の使い方を、説明を読んで実際に試しながら学ぶための資料です。
プログラミング言語の学習ではなく、「Claudeにうまく頼む・うまく使う」ことが目的です。

## 構成

```
claude_learning/
├── README.md                 この説明
├── lessons/                  読む資料
│   ├── 01_basics.md          Claudeとの基本的なやり取り
│   ├── 02_prompting.md       伝わる指示の出し方
│   ├── 03_claude_code.md     Claude Code の基本操作
│   └── 04_project_setup.md   CLAUDE.md・設定・再利用の仕組み
└── exercises/                手を動かす課題
    └── exercises.md          課題一覧とチェックリスト
```

## 進め方

1. `lessons/` を 01 から順に読む
2. 各レッスンの「やってみよう」を実際に試す
3. `exercises/exercises.md` の課題にチェックを入れていく

## 学習ロードマップ

| 段階 | テーマ | ゴール |
|------|--------|--------|
| 1 | 基本 | 質問・依頼・修正の往復ができる |
| 2 | 指示の出し方 | 目的・背景・条件を含めた依頼ができる |
| 3 | Claude Code | ファイルの読み取り・編集・コマンド実行を依頼できる |
| 4 | 設定と再利用 | CLAUDE.md で毎回の前提を共有できる |
